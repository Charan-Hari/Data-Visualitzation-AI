# Demo dataset sources

The Pages demo uses public datasets so the charts show realistic data shapes.

- **Wine Quality** — UCI Machine Learning Repository, red Vinho Verde wine measurements. [Dataset](https://archive.ics.uci.edu/dataset/186/wine+quality)
- **Bike Sharing** — UCI Machine Learning Repository, daily bike rental counts and weather fields. [Dataset](https://archive.ics.uci.edu/dataset/275/bike+sharing+dataset)
- **World Population** — World Bank data distributed by DataHub under the Public Domain Dedication and License. [Dataset](https://datahub.io/core/population)
- **US Births** — FiveThirtyEight data repository, Social Security Administration births by date. [Dataset](https://github.com/fivethirtyeight/data/tree/master/births)

The files are included for demonstration and visualization. Review each source's license and attribution requirements before using them in a commercial product.
